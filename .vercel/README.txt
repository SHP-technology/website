Hostinger Control Panel (hPanel) me login karein.
Left menu me Domains par jayein aur shptechnology.online select karein.
DNS / Name Servers (DNS Zone Editor) par click karein.
Naya DNS record add karein:
Type: CNAME (ya A record agar IP address hai)
Name / Host: api
Target / Points to: Aapke API server ka domain (e.g., my-api-server.onrender.com ya IP 123.45.67.89)
TTL: 300 ya Default
Add Record par click kar dein.
